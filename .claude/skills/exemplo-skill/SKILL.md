# Exemplo de Skill

Este é um skill de exemplo. Substitua este conteúdo pelas instruções do seu skill.

## Como usar
Quando o usuário digitar `/exemplo-skill`, faça o seguinte:

1. Explique o que este skill faz
2. Execute as ações configuradas aqui
3. Retorne o resultado ao usuário

## Instruções para criar seus próprios skills

Copie esta pasta, renomeie para o nome do seu skill e edite este arquivo com suas instruções personalizadas.

Coloque na pasta correta conforme o escopo desejado:
- Global (todos os projetos): ~/.claude/skills/nome-do-skill/SKILL.md
- Só este projeto: .claude/skills/nome-do-skill/SKILL.md
